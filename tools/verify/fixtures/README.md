# Что здесь и почему

Минимальная игровая директория, которой хватает движку, чтобы дойти до
нарисованного кадра. Это **не** замена ассетам: три файла из четырёх — цена
входа, а не содержимое.

| Файл | Зачем |
|---|---|
| `base/default.cfg` | без него движок не стартует вовсе |
| `base/shaders/jkx_smoke.shader` | рендерер не заканчивает `R_Init` без хотя бы одного `.shader` |
| `base/ui/menus.txt` | без него `Com_Error(ERR_FATAL)` в `UI_LoadMenus` |
| `base/ui/jkx_smoke.menu` | меню обязано называться `mainMenu`, иначе движок бесконечно перезагружает список |

С этими четырьмя файлами `tools/verify/smoke_headless.sh` доходит до обычного
цикла кадров, снимает скриншот и выходит по `quit` с кодом ноль. До того тест
останавливался на отсутствующем `ui/menus.txt` — то есть проверял инициализацию
и ни одного нарисованного пикселя.
